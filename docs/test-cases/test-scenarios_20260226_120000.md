## Feature: [User Registration] (POST /api/v1/users/register) [CRITICAL]

> Domain: Security (account creation, password validation, 2FA token generation).
> External API dependency: SMS Gateway — mock required for all POS and failure scenarios.
> Uniqueness constraints: email (case-insensitive per RFC 5321) + phone must both be unique.
> Idempotency: 5-minute cache window. Body mismatch within window → 400 IDEMPOTENCY_KEY_MISMATCH (spec-defined).
> Contradiction resolved: same Idempotency-Key + same body + cache expired + PENDING record exists → 409 Conflict (uniqueness wins, NOT a new 201 Created).
> Contradiction resolved: email case-normalization (RFC 5321 lowercase) + uniqueness → ALEX@example.com conflicts with stored alex@example.com → 409 Conflict.
